# 微宇宙 · MICROCOSM

> 微宇宙的本质，是对于「规则的数量」与「结果的数量」之间差值的一次判断——
> 写进去三条，长出来的不止三条，那多出来的部分，即本作唯一的作者。
>
> **你只负责走位与瞄准。开火是自动的。**你要改的不是手速，是系统本身。

一个离线网页，同时也是一款独立游戏。无构建、无依赖、无后端。
双击 `index.html` 就能玩。断网可用。

---

## 一、它是什么

**定义 1.1（系统）**：系统是一组互相咬合的规则，其输出不等于任一规则的输出之和。

所以本作不写剧情，不写关卡，只写规则，然后让规则自己跑。
环上那几个槽位里放什么、哪两个挨着、养成室里把残渣换成什么——
这几处改动会穿过同一条编译路径（见 `world/modules.js` 的 `compile`），
最后落在主舞台的下一帧上。

**定义 1.2（涌现）**：涌现是设计者没有写死、而系统跑出来的那一部分结果。
即：它不是被设计出来的，它是被允许出来的。

**这一版最重要的一条改动**：元件是**局内资源**。
这一局捡到的元件，没装上、没合掉的那些在局末**退回熔炉**；

## 三、七个房间

- **装配台** 环形槽位，挨着的两个会自己搭上。等级越高的两个挨一起，长出来的越狠。装上去的元件从库存里扣，卸下来时还回来。
- **培养皿** 投两个元件，**当场扣、当场出**。合成不吃时间，吃元件。同一个东西投两次，长出它更高一级的那一版。
- **图鉴** 见过的元件、见过的东西、跑通的配方。可按种类或等级排序。没见过的留一个空位，等你在场上撞上。
- **养成室** 残渣换永久节点。六个分支：根 / 枝 / 脉 / 环 / 核 / 律。
- **阶跃** 累计击杀跨过门槛，场上换一条规则。旁边同时展示**纪元**。
- **流派** 游戏风格单开一间——它改的是规则（出场数、血量、掉落、速度），是角色玩法，不是外观，所以不再和皮肤并排摆在设置里。
- **设置** 皮肤、瞄准方式与无障碍开关。

七个房间共用一份状态：装配台改的，主舞台这一帧就生效。

## 四、场上的四类

常 / 精英 / 巨构几何体 / 华丽生物。四类在**出场权重、掉落份数、图鉴分组**上都分开算，
所以它不是装饰——它是你决定「这一只值不值得单独转身」时读的那一行。

- **常** 在场上的大多数。一只一只看都不难，它们靠数量。
- **精英** 比同波的东西厚一截，必带一枚看得见的精化徽记，死了掉两份。
- **巨构几何体** 巨构。大、慢、极厚，它不是敌人，它是一块会还手的地形。死了掉三份。
- **华丽生物** 走得花，弹也花。它的威胁是密度，不是厚度。

巨构与精英的出场权重比常类低一个数量级：它们一多，场面就读不完了。

**曲线更陡，且陡在后段**：血量走 `1 + 0.16w + 0.0098w² + 0.00009w³`。
三次项只在后段发力，所以前十几波几乎不受影响——「更陡」兑现成的是后段真的追得上构筑。

**局内成长随机化**：开局先摇一份**脾气**——整条曲线的陡度（0.82 ~ 1.28）、
每一波上下抖多少（0.10 ~ 0.30）、整体偏厚还是偏薄，以及对四类各自偏爱多少。
之后每一波再按这份脾气抖一次。所以同一个编号的第 20 波，这一局和上一局不是同一个数。
但同编号同局数永远得到同一份，重开可复现。脾气摊在主舞台的 HUD 上，是看得见的。

**Boss 各有自己的出手**：八个 Boss，六套出手（圈 / 螺旋 / 光束 / 召小 / 正交线 / 横扫）。
破一件，出手快一分——这是「先破件」唯一的即时回报。

## 五、三条判定规则

这一版把三件事从「数值」升格成了「规则」。它们不参与成长，也不被成长改掉。

**判定点**：角色的**可见体积**（`p.r`）与**受击判定**（`p.hitR`）是两个数。
受击只看中心那一点点。所有伤害来源——接触、敌方弹、区域、光束、余烬灼烧——
都读同一个判定点。

旧版把整个可见体积当碰撞箱，于是「收束」「虚身」这类减体积的元件
**实际上一点没变强**：画变小了，判定照旧。现在两者分开，减体积是真的难被打中。

**受击冷却**：受击后进入 **60 帧（= 1 秒 @60fps）**的冷却，这一秒内**所有**伤害都进不来。
它存在的理由是让死亡读得出因果，而不是「一帧被打死十次」那种读不出前因后果的结算。
养成全满也还是一秒——因为它是一条判定规则，不是一个数值。

**手动瞄准**：移动只认键盘，方向只认鼠标。开火**节奏**仍然是自动的（节奏是系统的一部分），
方向是你的。旧版鼠标能拖着人跑、也能自动选敌，两套控制在同一帧里打架，
表现出来就是「有时候准头自己飘掉」。现在输入端只有一条路。
设置里另有「锁最近」，那会把方向换回自动选敌——那是另一个玩法，不是补丁。

环轨与分身任何时候都各自选敌，它们是「系统自己跑」的那一层。

## 六、随机住在哪里

**定义 4.1（随机）**：随机不是把数字搅乱，随机是同一份规则每一局落在不同的位置上。

所以本作的随机全部走派生种子（见 `core/seed.js` 的 `rngFrom`）：
同编号 + 同局数 = 同一张织构，等价于同一局。换编号 = 换一整套，
重开一局 = 织构重抽，但抽法还是那一种——抽法是规则，抽到什么是结果。

| 表 | 位置 | 抽的时机 | 管多久 |
|---|---|---|---|
| `WEAVE` 织构 | `world/anomaly.js` | 开局抽两缕 | 整局 |
| `EVENTS` 当波事件 | `world/anomaly.js` | 每波抽一条 | 这一波 |
| `ROLLS` 掉落方差 | — | **已删除** | — |
| `VARIANTS` 敌人变体 | — | **已删除** | — |

- **织构**：这一局偏向哪一边（更挤 / 更快 / 更厚 / 掉得更多 / 场地一直缩……）。总台上明写。
- **当波事件**：这一波撞上什么。抽不到也是一条结果——空也是一条。
- **织构 + 事件 + 波相 + 风格 → `this.rule`**：合流点只有一个，在 `Engine.prototype.recalcRule()`。

另：异常元件本身每一局重掷一次。它叫异常，就该每一局都不太一样。

## 七、这一版删掉了什么，以及为什么

| 删掉的 | 换成的 | 原因 |
|---|---|---|
| **变异**（每 5 波一条永久规则，共 10 条） | **波相** `PHASES`（5 条，条数封顶） | 十条叠满之后没有任何一张表能说清场上正在发生什么。根因是**规则多到读不完**。封顶 5 条之后，你始终知道现在有哪几条在生效。 |
| **变体**（看不见的敌人百分比堆叠，12 种） | **精化** `ELITES`（7 种徽记） | 旧版你只知道「这一只不太一样」，至于是哪里不一样得猜。看得见才可以针对；看得见的堆叠才读得下去。 |
| **掉落方差** `ROLLS` | 掉落只出一件 | 多一层骰子就多一层读不懂。残渣改从波相与纪元来。 |
| **培养皿的挂钟等待**（12–240 秒） | 瞬时合成，代价是两个元件 | 旧版代价是「等待」而不是「元件」，于是可以无限白嫖，合成因此毫无意义。 |
| **重力井 / 漂移墙 / 潮汐 / 蚀** | **几何障**（波相「障」，有血量） | 分散在四条变异里、且大多不可见。合并成一种「挡弹也挡人、可以被敲掉」的东西之后，它重新变成了一个取舍。 |
| **自动机**（`core/automata.js` + 序室 + 养成室「序」分支 13 个节点） | — | 它要玩家先读两张表（程序表 + 触发器表）才知道这一波发生了什么，而它做的事又全部可以在装配台与养成室里手动完成。它提供的不是新的决定，只是把已有的决定提前做了。 |
| **终端**（`rooms/terminal.html`） | — | 指令与隐藏层是开发用的后门，不是玩法。删掉之后房间从九间收到七间。 |

这一版的「眠」也从「每 80 帧重新蓄一次力、冲速叠 1.9 倍」改成
**一辈子只冲一次**：远处盯着你 → 蓄力 46 帧（外环可见地收）→ 冲一次 → 力竭，只剩 35% 速度。
旧版那不是敌人，那是节拍器——你走位躲不开它，因为它的节奏与你的位置无关。

## 八、局外成长

### 养成室：6 个分支，53 个节点

`根` 本体底子 · `枝` 掉落与拾取 · `脉` 培养皿 · `环` 装配台 ·
`核` 阶跃与终局 · **`律` 纪元**

`律` 是后加的，因为前面五支只能让你变得更强，变不出**不一样**。

### 纪元（律）：改的是尺子

阶跃改的是「场上会发生什么」，**纪元改的是「数字本身怎么长」**。
阶跃跨过门槛，世界换一条规则；纪元跨过门槛，**尺子换一把**。

七个键全是乘算（中性值 1）：`hpWave` 血量坡度 · `dropWave` 掉落 ·
`rateWave` 开火间隔 · `resWave` 残结算 · `bossWave` Boss 血量 ·
`waveGain` 一波时长 · `edge` 收边强度。

所以旧存档里的「伤害 40」到了新纪元不再等于旧纪元的「伤害 40」——
数量级上去以后，原来那个数就不再是原来那个意思。
养成室的「律」分支能改它：门槛、坡度、Boss 三样都可以放宽。

## 九、皮肤与风格

两张表，两种东西，正交。

- **皮肤**（6 套）**只改颜色**。判定逐字相同。皮肤表里不许出现任何参与判定的字段。
- **风格**（7 种）**改规则**：素 / 疾 / 厚 / 稀 / 密 / 静 / 远。
  风格改的是「这一局的形状」，不是「这一局的难度上限」——上限归 `MC.eff`，风格只乘在上面。

任何皮肤都能配任何风格。换皮即时生效，主舞台、房间与内置说明一起换。

## 十三、老实交代

- **声轨不进任何判定**，默认静音，要你先点一下才出声。它另行记账，不写进卷宗。
- **冷静模式只钳上限**，不偷偷给你加成。规则一条不改。
- **受击冷却固定一秒**，不随任何养成、风格或纪元变化。
- 存档在浏览器本地（`localStorage`）。`file://` 下 iframe 可能被挡，房间会退化成「独立打开」，存档与主舞台仍是同一份。
- **已知限制**：养成室的孵化靠挂钟时间，改系统时间会让它跳。
- **已知限制**：内置说明里的数据由同一份声明表渲染，表改了它就改；它不维护第二份数据。
- **已知限制**：无头测试守的是运行时错误与数值不变式，不是像素。画得好不好看，得你自己开一眼。
- **元件是局内资源**这一条与旧版「元件库存 [局外]」直接冲突。以本条为准，见内置说明的勘误注 4。

## 十四、勘误

- **注 1（概念增加 1）**：本文说「随机不是把数字搅乱」。原定义漏了一层——
  随机同时也是「同一份规则落在同一位置上」的反面，即：可复现是随机的前提，
  不是它的对立面。本作的每一处随机都能由编号推回去，这一点到为止。
- **注 2（概念增加 2）**：乘算类的键（`rateMul` / `dropMul` / `radiusMul` / `hitMul`）
  写的是「相对 1 的偏移」，所以在 `compile` 里必须**相乘**，绝不能相加。
  相加会让两个「收束」变成 0.82 + 0.82 = 1.64——从「更小」翻成「更大」。
  同样地，中性值一律是 1 而不是 0：乘算的键从 0 起会永远是 0。
- **注 3（概念增加 3）**：`eliteChance` 与 `bossEvery` 是**基线**而不是乘数。
  波相「盛」把它们「抬到」0.34 与「压到」5，而不是乘上去——
  10 × 5 = 50 会把 Boss 推得比不开还稀。
